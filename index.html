Reliability Lab
คู่มือและข้อมูล

ข้อมูลสำหรับผู้ติดต่องานห้องแลป

การใช้งาน Line Official

ติดต่อห้องแลปผ่าน Line Official เพื่อสอบถามข้อมูล รับประกาศ และแจ้งปัญหาการใช้งาน

วิธีเพิ่มเพื่อน

  1. เปิดแอป Line แล้วแตะ “เพิ่มเพื่อน”
  2. สแกน QR Code หรือค้นหาด้วย Line ID ของห้องแลป
  3. กด “เพิ่ม” แล้วรอข้อความต้อนรับ
  4. เลือกเมนูจากแถบด้านล่างของแชตเพื่อดูข้อมูลที่ต้องการ

ใช้ทำอะไรได้บ้าง

ประกาศและข่าวสารตารางปิด-เปิดห้อง แจ้งซ่อมบำรุง
สอบถามข้อมูลสอบถามตารางทดสอบและเครื่องมือ
แจ้งปัญหาแจ้งปัญหาการใช้งานโปรแกรม e-Far

เวลาทำการตอบแชท: จันทร์–เสาร์ 07:30–17:30 น.
